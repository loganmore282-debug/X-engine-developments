# Chocolate — project memory (read this first)

**What it is:** Chocolate is a copy of **Mint** (Mint branch `claude/mint-build`, copied after note 4ax = TavuPay recharges + payouts) renamed with
`node set-brand.js "Chocolate"`. Same code, same money rules, same admin panel, same green/cream member design as Mint at the time of the copy.
From here Chocolate and Mint change independently; the owner will say what to change. Every money/auth/payout rule and why is in
`docs/SODA-LOG.md` (read its "Money-safety" and "Status log" parts before touching payment, payout or withdrawal code) and in the inherited Status notes below.

The owner speaks plainly, wants things done (not lots of questions), keeps answers short, hates abbreviations ("UGX 23,000", never
"23k"), and does not want features nobody asked for.

## Where things are (all under `chocolate/`)
- `server.js` (backend, MongoDB only, no Firebase), `db.js`, `session-policy.js`, `service-account.js`, `totp.js`
- `user-src/` (member app: `index.html`, `original_module.js`) -> `node build-core.js` -> `user/`
- `admin-src/index.html` -> `node build-admin.js` -> `admin/`
- Always rebuild after editing `-src`, bump the cache name in `user/sw.js` (`chocolate-shell-vN`) and `admin/sw.js` (`chocolate-admin-shell-vN`),
  run `npm run test:audit` (4-9 minutes; wait for exit 0), commit, push to **`claude/chocolate-build`**.
- Install dev tools with `npm install --include=dev` (acorn, jsdom, javascript-obfuscator are needed by the tests/build).
- `node set-brand.js "Name"` renames the app everywhere again if the name ever changes (files must be git-tracked).

### One-time backend setup (owner runs it on the VPS as root)
1. Atlas: Database Access -> add user `chocolateapp` (readWrite on database `chocolate` only); Network Access already allows the VPS.
2. One command: `git clone --filter=blob:none --no-checkout --branch claude/chocolate-build "$(git -C /srv/mint-src remote get-url origin)" /srv/chocolate-src && cd /srv/chocolate-src && git sparse-checkout set chocolate && git checkout && bash chocolate/deploy/first-setup.sh`
   It installs packages, asks (hidden) for the MongoDB connection string and CHECKS it connects, asks for the admin password, writes
   `/srv/chocolate-secrets/secrets.local.js`, starts pm2 `chocolate-server`, and tests `/health`.
3. Updates until a domain is set: `bash /srv/chocolate-src/chocolate/deploy/quick-update.sh` (restarts only Chocolate).
4. Domain: `bash /srv/chocolate-src/chocolate/deploy/set-domain.sh yourdomain.com` (prints the two DNS A records; same flow as Mint, note 4af). Afterwards: GitHub webhook to `https://<app host>/k7x2/deploy/webhook` with `DEPLOY_WEBHOOK_SECRET`, gateways via `deploy/show-links.sh`.
5. Temporary preview by IP: `bash /srv/chocolate-src/chocolate/deploy/preview.sh on` serves the app at `http://<vps ip>:8098/` and the admin at `http://<vps ip>:8098/Pw3k9zt6/` (plain HTTP, design work only). `preview.sh off` removes it.
6. Push notifications: reuse Mint's Firebase key: `bash /srv/chocolate-src/chocolate/deploy/copy-secret.sh FIREBASE_SERVICE_ACCOUNT /srv/mint-secrets/secrets.local.js` (second argument = the file to copy FROM).
